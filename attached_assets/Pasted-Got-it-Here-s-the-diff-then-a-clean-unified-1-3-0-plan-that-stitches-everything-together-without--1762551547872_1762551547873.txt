## 4) Location Intelligence (from b, privacy-tight)

**Principles**

* **Server stores only the human-readable `tasks.location` string.**
* **Live coordinates never leave the device** (IndexedDB/localStorage).
* Geofence checks and cooldown timers run **client-side**.

**Client services**

* `location-notifications.ts`

  * Requests permission (Geolocation + Notifications).
  * Watches position (throttled).
  * Matches nearby tasks by local store of `{name:"Office", lat, lon, radius}` mapped to textual `tasks.location`.
  * **30-min cooldown** per location key.

**API**

```
GET /api/tasks/autocomplete/locations   // unique task.location strings (text only)
```

**Settings (from b)**

* Toggles: Location Reminders (on/off), Cooldown (e.g., 30m), Manage Saved Places (name + radius), Voice Input (on/off).
* Clear explanations of local-only processing.

**Geofence sketch**

```ts
const withinRadius = (a:{lat:number,lon:number}, b:{lat:number,lon:number}, rM:number) => {
  const R=6371000, toRad=(d:number)=>d*Math.PI/180;
  const dLat=toRad(b.lat-a.lat), dLon=toRad(b.lon-a.lon);
  const s = Math.sin(dLat/2)**2 + Math.cos(toRad(a.lat))*Math.cos(toRad(b.lat))*Math.sin(dLon/2)**2;
  const d = 2*R*Math.asin(Math.sqrt(s));
  return d <= rM;
};
```

**Unified notifications**

* In-app toast for immediate actions; **OS Notifications** for geofence reminders.
* Single wrapper picks best channel available.

## 5) Voice Input (from b)

* Mic buttons on **Activity** and **Notes** fields.
* Web Speech API where supported; fall back to a modal that explains unavailability.
* Respect settings toggle; no recording unless user taps mic.

```ts
const startDictation = async (onText:(t:string)=>void) => {
  // @ts-ignore
  const SR = window.SpeechRecognition || window.webkitSpeechRecognition;
  if (!SR) return { supported:false };
  const rec = new SR(); rec.lang='en-US'; rec.interimResults=false;
  rec.onresult = (e:any) => onText(e.results[0][0].transcript);
  rec.start(); return { supported:true };
};
```
