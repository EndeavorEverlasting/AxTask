# Workflow handoff contract

At workflow closeout record: repository/branch/head, owned and forbidden scope, files/artifacts changed, validators actually run with pass/fail/skip, strongest proof level, gaps/risks, preserved work, commit/push/PR state, and the first executable next action with owner, dependency, expected artifact, and completion gate. Use `.ai/handoff/final-handoff-template.md` only when a rendered handoff artifact is required.
